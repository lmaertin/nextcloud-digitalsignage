# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-01-24

### Added
- Enhanced language support documentation
- Code comments translated to English for better maintainability
- Improved translation helper tool

### Changed
- Updated README with more detailed installation and configuration instructions
- Improved code documentation and inline comments

### Fixed
- Minor bug fixes in translation handling

## [1.0.0] - 2026-01-20

### Added
- Initial release
- Calendar integration with Nextcloud calendars
- Image slideshow from Nextcloud folders
- Weather information via Open-Meteo API
- Token-based public display access
- Configurable settings UI
- Multi-calendar support
- Event filtering by keywords
- Database migrations
- Internationalization support (German, English)
- Translation helper tool
- Token management system
- Public API endpoints
- Responsive display layout

### Security
- Token-based authentication for public displays
- Secure token generation and validation
